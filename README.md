# CIAM System Atlas Data

Maschinell erzeugte, öffentliche Datenquelle für [Eye-Net](https://ciam.archivalia.ch).

`graph.json` enthält nur die bereits in Eye-Net sichtbaren Strukturmetadaten. Quelltexte, Zugangsdaten, generierte Dateien, Caches und virtuelle Umgebungen werden nicht veröffentlicht. `version.json` ist eine kleine Prüfsumme, mit der offene Browser Tabs einen neuen Stand erkennen.
